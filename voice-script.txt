How this works: record or generate a voice clip for any line below, save it as an audio file (mp3, wav, m4a or ogg) and name the file with the 8-character ID shown in front of that line, for example 3b6b90e4.mp3.
Then open the game, go to Settings, and use "Import voice recordings" to pick the files. A recording you import replaces the built-in one for that line.
Recordings are stored in your own browser on that computer. If you clear the browser data or use another computer, import them again.
The ending screen paragraph includes your score, so it always uses the computer voice.
